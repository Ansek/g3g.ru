# g3g.ru
Прототип сайта салона сотовой связи. На странице сайта рабочей вкладкой является только "Магазин", остальные неактивны.  
Реализованы CRUD-операции через REST API для работы с таблицами категорий, товаров, пользователей и адресов магазинов.  
Swagger-спецификация: *http://127.0.0.1:5000/docs/*  
Текущая версия сайта содержит:
- главную страницу;
- страницы для выводов товаров по категориям с поиском по цене;
- авторизацию, регистрацию и изменение учётных данных;
- для администраторов: формы редактирования таблицы БД.

В проекте использовались: Flask, PostgreSQL, Alpine.js и Bootstrap.

## Запуск
Реализован командный файл ***run.bat***, который создает виртуальное окружение Python, загружает библиотеки и развертывает проект Flask в режиме отладки.

Предварительно требуется подготовить СУБД и создать базу данных с именем, которая будет использована в строке подключения (переменная среды ***DATABASE_URL***, таблицы создаются автоматически после запуска ***run.bat*** через SQLAlchemy).  
На данные момент ***DATABASE_URL*** в файле ***run.bat*** настроена на СУБД PostgreSQL c пользователем seller (пароль: 123) и подключением к базе данных flask_db.

В папке scripts содержится SQL-файл для создания аккаунта пользователя admin с паролем: 123. Вход через форму логина осуществляется по адресу *http://127.0.0.1:5000*. Также скрипт ***filldb.py*** добавляет в базу данных через REST API три категории товаров: смартфоны, планшеты и телефоны, а также по 20 товаров для каждого (при этом требуется авторизация пользователя admin) и 5 адресов магазина.
## Задание
Разработать информационную систему с web-интерфейсом, используя
современные каркасы разработки.
Процесс разработки информационной системы состоит из следующих
этапов:
1. Согласно выбранной теме изучить предметную область и определить
функциональные и нефункциональные требования к информационной
системе. Согласовать требования с преподавателем.
2. Выбрать каркас(ы) для разработки информационной системы (фреймвоки) как для серверной части (back-end), так и для клиентской части (front-end).
3. Разработать архитектуру создаваемой информационной системы.
4. Разработать макет пользовательского интерфейса информационной системы (статические web-страницы, призванные продемонстрировать как в будущем будет выглядеть пользовательский интерфейс).
5. Реализация информационной системы:  
a. Выбор программного-технических средств разработки.  
b. Выбор вспомогательных библиотек (шаблонизаторов, кодогенераторов и иных инструментов).   
c. Разработка структур данных (в виде ER-модели базы данных).   
d. Разработка основных страниц информационной системы. Верстка и
совмещение с различными видами браузеров.   
e. Соединение статического контента с базой данных посредством серверных сценариев, используя возможности каркаса разработки.   

При разработке необходимо максимально широко использовать фреймвоки (такие как Spring MVC, Django, Node.js и другие) как для «backend», так и для «frontend», шаблонизаторы, библиотеки различного назначения.  
Запрещается использовать content management systems (CMS), фреймвоки типа Wordpress, Joomla, Drupal или их аналоги.
